## F01 — `confidence` (исходно заявлен разрыв 0,3964; после перепроверки — 0,0397)

> Уточнение: заявленные 0,3964 были артефактом сравнения (средняя уверенность на сбалансированной выборке против precision при prevalence). Корректный компаратор — prevalence-взвешенная средняя на тех же строках; для isotonic+поправки он даёт 0,009–0,0397. Варианты ниже переоценены с учётом этого.

| Вариант | Плюсы | Минусы | Рекомендация |
|---|---|---|---|
| **A. Platt на log-odds (score → logit → sigmoid)** | Стандарт, мало параметров, монотонно | При обучении на сбалансированном наборе хвост всё равно завышается — тот же класс ошибки | резерв |
| **B. Isotonic на prevalence-согласованной выборке (1:1000)** | Прямо калибрует под развёртывание | Нужно много данных в хвосте (≥3000 benign при 0,1 % FPR), нестабилен в хвосте | позже, с данными |
| **C. `confidence = PPV(TPR,FPR,prevalence)` таблицей в рабочей точке** | Честно, дёшево, нет хвостового завышения | Confidence становится ступенчатым (по порогам), не per-sample | **принять сейчас** |
| **D. Явная LR-модель (плотность/энергия)** | Теоретически точный per-sample | Существенно сложнее, новый код | не сейчас |

**Рекомендация: C сейчас, B после накопления данных; A не закрывает проблему — не применять как основной.**
