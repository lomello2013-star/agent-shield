# v1 scope: что заморожено до юрлица

**Дата:** 2026-11-14  
**Решение:** D-014/D-015 приняты для v1; D-016 — freeze.

## 1. Принятые метрики v1

| Метрика | v1 (принято) | Исходная цель | Статус |
|---|---|---|---|
| E7 | **TPR ≥0.90 @1 % FPR**, PPV ≥0.50 @0.05 % | 0.95 @0.05 % | v1 цель достигнута (0.90136 / 0.5642); 0.95 — research |
| F10 | **FBR ≤15 %** lab | 10 % | 13.33 % достигнуто; 10 % — pilot с hash/update feed |

Исходные 0.95 @0.05 % и 10 % не отменены: они остаются research/pilot-целями
и не являются релизным гейтом v1.

## 2. Заморожено (требует юрлица/EV/HLK)

| Пункт | Почему заморожен | Условие разморозки |
|---|---|---|
| EV code-signing сертификат | CA требует проверяемое юрлицо; ключ в HSM | ИП/ООО + EV |
| Partner Center / Hardware Dev Center | верификация бизнеса | юрлицо + EV |
| HLK/WHQL и production-подпись драйвера | подпись Microsoft после HLK | EV + HLK + Partner Center |
| WDAC CI policy signing | требует EV-подписи | EV/CI-инфраструктура |
| Production HSM/ключ подписи | key custody/attestation | сертифицированный HSM/партнёр |

**Не заморожено:** user-mode v1, Linux eBPF-агент, test-signed драйвер в lab,
24h soak, red-team, документы, lab-ключи на offline USB.

## 3. Что такое v1

- Windows: user-mode сервис + правила + audit; драйвер — **только test-signed lab**,
  не для распространения.
- Linux: eBPF-агент (systemd, queue, SHA256+Ed25519 lab-манифест).
- Метрики: E7/F10 в принятых границах; holdout 5/5; 24h soak 100 %.
- Поставка: исходники + lab-инструкции; без production EV/WHQL.

## 4. HSM на USB

Для **lab-подписи** используется offline USB (LUKS + 2-of-3), см.
[hsm-usb-plan.md](hsm-usb-plan.md). Это **не HSM** и не заменяет EV-токен;
production-подпись остаётся замороженной.

## 5. Критерий разморозки

Разморозить можно только после появления юрлица (или партнёра с EV/Partner
Center). До этого не покупать EV «в стол» и не начинать HLK-сабмит: без
юрлица цепочка не завершается.
