# S0.0c — решения по контракту и коннектору

> Гейт S0.0c. Принятые решения зафиксированы; альтернативы — в
> [docs/stml-decisions.md](stml-decisions.md).

## 1. Транспорт коннектора (ADR D15)

**Принято:** Python-клиент к `core/ipc.py` (pickle) + внутренний JSON-RPC на
`127.0.0.1:<dynamic>` (line-delimited, 1 MiB). Pickle не пересекает границу
коннектора.

**Почему:** ядро агента не меняется; `core/ipc.py` уже имеет authkey/роли/лимит;
Rust-адаптер избыточен.

**Альтернативы:** второй HTTP-прослушиватель в агенте (отклонено — меняет ядро);
Rust-коннектор (отклонено — сложнее и без выгоды).

## 2. Семантика RPC (исправлено по коду)

| RPC | Семантика | Использование |
|---|---|---|
| `kill_switch` | kill **правила** по `rule_id` | не «остановка агента» |
| `shutdown` | завершение агента | глобальная остановка |
| `quarantine` | изоляция **объекта/файла** по `path` | не «изоляция агента» |
| `immutable_check` | `verify_immutable()` — fingerprint immutable-политики | read-only |

`suspend`/`resume` **не эмулируются** через `kill_switch`/`shutdown`: это
серверный флаг «STML перестаёт слать команды агенту».

## 3. Разрыв контракта

- `get_inventory`, `get_policy_state` отсутствуют → fallback через `*.jsonl`.
- `suspend`, `resume` отсутствуют → серверный флаг.
- `report_id` генерирует **коннектор** (persistent SQLite), не агент.

## 4. Multi-tenant (ADR D14)

**Принято:** single-tenant MVP; `tenant_id` в схеме с S0; финализация — S8.
**Альтернативы:** schema-per-tenant сразу (отложено), без tenant_id (отклонено —
ломает миграцию).

## 5. Event bus (ADR D16)

**Принято:** Postgres outbox на S1; NATS при >1k; Kafka — если уже есть кластер.
**Альтернативы:** NATS сразу (отложено), Kafka сразу (отклонено).

## 6. Соглашение с владельцем агента

- Уведомление о breaking changes в `core/ipc.py` / `schemas/v3` — ≥2 недели.
- Владелец агента: заказчик (см. `docs/owners.md`).
- Статус: зафиксировано письменно в этом документе; отдельная подпись — при
  первом изменении контракта.

## 7. Границы S0.1a

- Подпись пакета и `key_id` — S0.1b.
- mTLS — S2/S3.
- `enrolment` — S1 (VS1 работает без сервера, в консоли).
- Rust-порт — вне области S0–S3.
