## 5. Что быстрее всего поднимет готовность

1. **Прогнать установку на чистых машинах** (Windows MSI, Linux .deb/systemd) — проверит упаковку end-to-end (сейчас 60/50 %).
2. **Нагрузочный тест сервера** (N агентов, поток отчётов, отказ узла) — закроет главный пробел 45 %.
3. **IMA appraisal** — довести подпись/политику (Linux-целостность до 80 %).
4. **Внешнее ревью и приёмка** — без них гейт качества формально нулевой.
5. **7-дневный soak** — если есть always-on хост.

## 6. Вердикт

- **Пилот (Linux, режим наблюдения + обратимое реагирование):** возможен при 1–2 неделях доводки упаковки и нагрузочного теста.
- **Пилот Windows:** только user-mode и только как мониторинг; драйвер/TI — после юридического разблокирования.
- **Production EDR:** **нет** — нет подписи, независимого ревью, red-team и пилота; сервер без HA.
- **Сервер:** годится для пилота на одном узле, не для production-нагрузки.
