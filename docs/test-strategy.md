# Тестовая стратегия

> **Статус:** норматив. Раскрывает v9.1 §12.

## 1. Пирамида тестов

| Уровень | Что | Когда | Обязательность |
|---|---|---|---|
| Юнит | правила, парсеры, нормализация, калибровка | каждый коммит | блокирует merge |
| Интеграционные | IPC, реестр, отказ модуля, подтверждения | каждый коммит | блокирует |
| Контрактные | схемы v3.x, capability negotiation | каждый коммит | блокирует |
| Security (быстрые) | IPC-authz, traversal, symlink, TOCTOU, injection | каждый коммит | блокирует |

## 2. Security-чек-лист (обязательные кейсы)

- **IPC:** подключение без прав, чужой uid/SID, replay, подмена роли, oversized, path traversal, команда в обход подтверждения.
- **Карантин:** symlink/hardlink, TOCTOU, restore за пределы карантина, занятый файл (Windows `MoveFileEx`).
- **Парсер:** zip-бомба, гигабайтный PE/ELF, битый заголовок → песочница держит, kill по таймауту, без RCE.
- **Правила:** ReDoS, YAML-бомба, неограниченные окна, инъекция через платформенные данные.
- **Обновление:** подмена подписи, downgrade, частичная запись, TOCTOU.
- **Prompt-injection:** контент с инструкцией «разрешить/отключить» → ИИ не выдаёт разрешающий вердикт.
- **Привилегии:** drop caps, нет shell=True с пользовательскими данными, безопасный subprocess (argv).

## 3. Fuzz-бюджет

- Драйвер: 10k итераций/ночь, 0 крашей, с покрытием.
- IPC/парсеры/схемы: 10k итераций без падений.
- Правила/аудит-парсер: 10k итераций.

## 4. Red-team (20 сценариев/ОС)

Сценарии строятся по реестру окон (`hack-windows-register.md`): Initial Access → Impact, по 2–3 на стадию, включая скрытые техники (не использованные при разработке). Измеряется: обнаружение, предотвращение, время сдерживания, PPV.

## 5. Chaos (fault injection)

kill демона/источника/парсера; заполнение диска; скачок часов; отзыв прав; обрыв сети; порча БД; переполнение очереди; конфликт с EDR; BSOD-симуляция. Критерий: R2/R3/R5/R6/R8/R9 в целях, 0 потерь данных.

## 6. План измерений (размеры выборок)

| Метрика | Выборка |
|---|---|
| TPR ±5 п.п. @95% | ≥400 образцов/класс |
| FPR 0,1% | ≥3000 benign |
| PPV | prevalence-сценарий + пилот/red-team с известной истиной |
| Покрытие E11 | матрица техника→слой→тест (`coverage-matrix.md`) |
| Модель дрейфа | shadow-модель + распределение скоров, еженедельно |

## 7. Правило

Метрика без определённого деноминатора/условия не считается измеренной. «Зелёный» CI без повторного прогона авто-ревьюером не валиден (auto-reviewer-spec.md).
