# Совместимость STML (S8)

## 1. Матрица ОС

| ОС | Версия | Статус STML | Примечание |
|---|---|---|---|
| Windows | 10/11 x64 | ✅ dev | сервер/коннектор проверены на Windows |
| Windows Server | 2019/2022 | ⚠️ не проверено | наследует Python-код |
| Ubuntu | 22.04/24.04 | ⚠️ не проверено | WSL/CI |
| Debian | 12 | ⚠️ не проверено | CI |
| RHEL | 9 | ⚠️ не проверено | CI |
| Fedora | 40+ | ⚠️ не проверено | CI |
| arm64 | — | ⚠️ не проверено | требует CI-матрицы |

## 2. Сосуществование с EDR

| EDR | Статус | Режим |
|---|---|---|
| Microsoft Defender | не тестировалось | `compat` при конфликте |
| CrowdStrike | не тестировалось | `compat` |
| SentinelOne | не тестировалось | `compat` |

**`compat` (проект):** при конфликте STML/агент переходит в наблюдение, не
блокирует; конфликт фиксируется в audit и policy. Код режима — в агенте (v9.1),
STML только хранит флаг `compat` в policy и показывает его в GUI.

## 3. Ограничения

- Реальные тесты с EDR не проводились: нет лицензий/стенда.
- Матрица ОС — целевая; runtime-проверка на CI.
- `compat` — политика, не автоматическое разрешение конфликтов.
