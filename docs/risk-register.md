## Приоритизация

Критические (влияние Критическое) — владелец security engineer, еженедельный статус. Высокие — PM, ежемесячный ревью. Средние — мониторинг триггеров.

## Правило ведения

- Новый риск добавляется через `decision`; закрытый — помечается `mitigated` с доказательством (тест/метрика).
- Триггер сработал → немедленная эскалация владельцу, а не отложенная.
